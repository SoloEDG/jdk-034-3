## 双人连体支撑关

顶栏「双人连体」进入连体关：两名攀爬者用一根定长横杆相连，交替出手。

- **支撑与腾手**：离点支撑不足时，只要横杆已绷直、杆力方向与失衡一致（轴向支援 ≥ 门槛）、且队友支撑足够，就能借杆腾手；借力会额外消耗体力并抬高横杆轴力。
- **杆长与负载**：预演同时检查两人间距是否超出杆长、杆端是否越出各自活动区、横杆轴向负载是否超限。动作中两体达到的最大间距也计入。
- **预演提示**：若一次动作因杆长、负载、松弛或对齐失败，会指出缺少的可行姿态，并给出「先让哪位队友移到哪个点」的具体补救。
- **联合解法**：内置规划器在总动作预算内搜索，给出「最少动作」与「最小峰值负载」两条候选，可逐步演示。
- **坠落 / 僵持**：任意一方坠落（或双方都无可行动作）时冻结双方姿态，记录保留导致问题的共同姿态，可在「连体记录」中回看。
